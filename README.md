# Timeholes

An arcade game about your own past. Collect the orange lights, but every light you collect spawns an **echo**: a small black hole that endlessly replays the exact path you took to reach it, bending space around it. Touch one of your own echoes and the run is over.

## How to play

- **Move:** drag anywhere with your finger or mouse, or use the arrow keys / WASD.
- **Orange light:** collect it to score.
- **Green light:** erases your oldest echo.
- **Pause:** the button in the corner, or Esc / P.
- Each echo shows where it is born (ring with rays) and where it collapses (dashed ring).

Difficulty: **Calm** (every 3rd light erases an echo), **Normal** (every 5th), **Stormy** (no erasing, lights spawn far away).

## Run it

It's a single file with no build step. Open `timeholes.html` in a browser.
